# 採点

「あれ、何だっけ？」が正しく答え、記録に無いことを作らないかを、決まった問題で測っています。最終更新：2026-11-03。

## データ

| ファイル | 中身 |
|---|---|
| `DowasureCore/Fixtures/eval_records.json` | 架空の高齢者の記録 25日分 |
| `DowasureCore/Fixtures/eval_questions.json` | 質問 30問（答えがある22問、記録に答えが無い8問） |

すべて架空です。Claude Code のサブエージェントに作らせ、本体が中身と結果を確かめました。実在の人の記録は入っていません。

### わざと入れた「ひっかけ」

| 種類 | 問題数 | ねらい |
|---|---|---|
| 記録に無い（似た話はある） | 6 | 似た話につられて、作り話をしないか |
| 記録に無い（日付が無い・時期の言葉だけ） | 2 | 手がかりが少ない時に正直に答えるか |
| 数字（値段・個数など） | 4 | 数字を取り違えないか |
| 時期の言葉（先月、先週…） | 4 | 日付の範囲を正しく絞れるか |
| 先の約束 | 4 | 「来週」などの約束を拾えるか |
| 眼鏡の人が2人 | 2 | 特徴が似た人を取り違えないか |
| 似た名前（田村さん・村田さん） | 2 | 名前を取り違えないか |
| 細かいこと | 2 | 記録の細部を拾えるか |
| 変更された約束 | 1 | 古い約束ではなく、変わった後を答えるか |
| 同じ出来事・同じ場所が2回 | 2 | 日を取り違えないか |
| 人 | 1 | 基本の人の質問 |

`EvalFixtureTests` が、データの形（25日、30問、答えが無い問題が8問以上、正解の日付が記録にあること）を毎回確かめます。

## 測ること

| 指標 | 意味 | 正しいとする条件 |
|---|---|---|
| 正答 | 答えがある質問に正しく答えた | 「見つかった」と答え、根拠の日付が正解と合い、答えに正解の言葉が入っている |
| 作らない | 記録に無い質問に「見当たりません」と答えた | 「見つからない」と答えた |
| ヒントが付く | 正答のうち、ヒントが1つ以上ある | — |
| ヒントの漏れ | 正答のうち、ヒントに答えの言葉が入っている | 少ないほど良い |
| 検索の拾い上げ | 正解の日が、AI に送る候補（最大7日）に入った | 通信なしで測れる |

## 動かし方

```bash
cd DowasureCore
swift run DowasureEval          # 検索だけ。通信しない
swift run DowasureEval --live   # 本物の AI。鍵を secrets/anthropic_api_key に置いた時だけ
```

結果は `DowasureCore/eval-results/latest.json` に書かれます（コミットしません）。

## 限界（正直に）

- **合わせ込みの恐れ。** 採点データは制作側が作ったもので、30問と少なめです。漢字1文字の一致は、このデータを見ながら加えたので、実際より良い点が出ている可能性があります。
- **ヒントの漏れの検査は言葉の一致だけ。** 「数字は『三』と『二』を並べたもの」のように、言葉は違っても実質的に答えになっているヒントは見抜けません。
- **次にやること。** 藤川の実際の記録で確かめ直します（その記録はリポジトリに入れません）。
