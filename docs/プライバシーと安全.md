# プライバシーと安全

**この文書で分かること：** ど忘れ相棒が「どこに何を送り、何を保存し、何を保存しないか」の全体と、声の中継所（`relay/`）の制限、考えた脅威とその対策です。書いてあることは、コード（リンク先）と [開発記録.md](開発記録.md) で確かめたことだけです。

最終更新：2026-11-07。

## ひとことで

- 記録は **iPhone の中だけ** に保存します。作者のサーバーに記録はありません。
- AI に送るのは **処理に必要な分だけ** です。どの日を送るかは iPhone の中で決めます。
- Claude API へは、iPhone から **直接** 送ります（作者のサーバーを通りません）。鍵は利用者（ご家族）のもので、iPhone のキーチェーンに入ります。
- 自然な声のための文だけは、作者の **声の中継所** を通って Google に届きます。中継所のコードには、文を保存する処理も、記録に書く処理もありません。

## 送るもの

| 送り先 | 送るもの | いつ | コード |
|---|---|---|---|
| **Anthropic**（Claude API） | その日に話した言葉の全部（時刻つきの行） | 「覚えておくことを話す」で1件話すたび、と「いまのを取り消す」の後。人・約束などを抜き出すため | `Recorder.extract`（[Services.swift](../DowasureCore/Sources/DowasureCore/Services.swift)） |
| **Anthropic**（Claude API） | 質問、今日の日付、関係のありそうな日の記録（最大7日分。要約・抜き出し結果・話した言葉の行） | 「あれ、何だっけ？」で聞いた時。候補の日が無い時は送らない | `Answerer.answer`、`Prompts.renderRecords`（[Prompts.swift](../DowasureCore/Sources/DowasureCore/Prompts.swift)） |
| **Anthropic**（Claude API） | 「はい」の一言 | 設定で鍵を保存した直後に1回だけ。鍵が使えるかを確かめるため | `ClaudeClient.checkKey`（[ClaudeClient.swift](../DowasureCore/Sources/DowasureCore/ClaudeClient.swift)） |
| **声の中継所**（作者の Vercel）→ **Google**（Gemini API の音声合成） | 読み上げる文、声の名前、話し方の指示（「ゆっくり、はっきり」など） | 「自然な声」で話す時。読み上げる文には、ヒント・答え・読み返し（「『…』ですね。覚えました。」）が含まれる | `CloudVoice`（[CloudVoice.swift](../DowasureCore/Sources/DowasureCore/CloudVoice.swift)）、[relay/api/speak.js](../relay/api/speak.js) |
| 同上 | 決まった言葉（「何を思い出したいですか？」など。個人の記録を含まない） | アプリに同梱していない声を選んだ時、最初に1回 | `Speaker.prewarm`（[Voice.swift](../App/Voice.swift)） |
| **Apple**（音声認識） | 話した声 | iPhone の中で文字にできない時だけ。できる時は端末内で処理する（`requiresOnDeviceRecognition`） | `VoiceInput.start`（[Voice.swift](../App/Voice.swift)） |

送らない場面：

- 設定で「すぐ話す声」（iPhone の声）を選ぶと、中継所にも Google にも何も送りません。
- 音量がほぼ0の時は声を出さないので、読み上げの文も送りません（`Speaker.sayAndWait`）。
- すべての記録をまとめて送ることはしません。候補の日は `Retriever.candidates` が iPhone の中で選びます。

## 保存するもの

| 何を | どこに | 補足 |
|---|---|---|
| 話した言葉と、その日の抜き出し結果 | iPhone のアプリ内の SwiftData（`StoredDay`、[Storage.swift](../App/Storage.swift)） | 1日1件。iCloud での同期はしていない（[project.yml](../project.yml) に iCloud の権限が無い） |
| 自分で思い出せた回（日時と、使ったヒントの数） | iPhone の UserDefaults（`RecallStore`、[RecallStore.swift](../App/RecallStore.swift)） | 最大1000件。何を思い出したかは保存しない |
| Claude API の鍵 | iPhone のキーチェーン（`APIKeyStore`） | 「この iPhone だけ」（`kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`）。バックアップで別の端末に移らない |
| 設定（声の種類・速さ、お知らせの有無と時刻） | iPhone の UserDefaults | — |
| Gemini の1日の上限に達した印（モデル名と時刻） | iPhone の UserDefaults | 1時間で切れる |
| 決まった言葉の声 | アプリに同梱（`App/Resources/Voice`）と、iPhone のキャッシュ用フォルダ | 決まった言葉4つだけ（`Speaker.fixedPhrases`）。個人の記録を含む声は保存しない（`Speaker.cacheURL`） |
| 記録の控え（書き出した時だけ） | 利用者が選んだ場所（ファイル App、AirDrop、メールなど） | 設定 →「記録の保管（ご家族向け）」→「記録を書き出す」。共有の前に、アプリの一時フォルダにテキストファイルを作る（`RecordsFile`、[SettingsView.swift](../App/SettingsView.swift)） |

- 機種変更：iPhone のバックアップ（iCloud バックアップや直接転送）がオンなら、記録も移ります。鍵は移らないので入れ直します。
- 消す：設定 →「記録の保管（ご家族向け）」→「記録を消す」→「すべての記録を消す」。確認の文に日数が出ます。

## 保存しないもの

| 何を | どうしているか | コード |
|---|---|---|
| マイクの音 | 音声認識に流すだけで、ファイルにしない | `VoiceInput.installTap` |
| ヒントや答えの声 | その場で再生するだけ。キャッシュするのは決まった言葉だけ | `Speaker.cacheURL` |
| 作者のサーバーでの記録 | 記録を受け取るサーバーが無い | — |
| 中継所での読み上げの文 | 受け取った文を Google に渡し、返ってきた音をそのまま返す。保存・記録の処理は無い。数えるのは「相手（IP）と時間ごとの回数」だけで、サーバーのメモリにだけ置く | [relay/api/speak.js](../relay/api/speak.js) の `POST`、`tooMany` |
| アプリのログ | 出しているのは声の経路・エラーの種類・声の一覧だけ。話した言葉や答えの文は出していない | `Speaker.trace` など |

## 声の中継所の制限

利用者に Google の鍵を入れてもらわないために置いた、小さなサーバーです（2026-11-07 に藤川さんが選択）。

| 制限 | 中身 |
|---|---|
| 鍵の置き場所 | Google の鍵はサーバーの環境変数 `GEMINI_API_KEY` だけ。アプリにもリポジトリにも無い。鍵が無ければ 503 を返し、Google を呼ばない |
| 通す頼み | モデルは2つ（`gemini-3.8-flash-lite-tts`、`gemini-3.8-flash-tts`）、声は3つ（Sulafat・Vindemiatrix・Achernar）だけ |
| 長さ | 読み上げる文は1〜400文字、話し方の指示は300文字まで |
| 組み立て直し | 届いた中身から必要な欄だけを取り出し、決まった形に組み立て直して送る。ほかの欄は捨てる（`validate`） |
| 回数 | 相手（IP）ごとに1時間20回、サーバー全体で1時間60回。超えたら 429 |
| 最後の歯止め | Google 側の枠（1モデル1日100回、Tier 1）。超えると Google が断るので、費用は増え続けない |
| 断られた時のアプリ | 予備のモデル → iPhone の声。決まった言葉は同梱の録音で鳴る |

正直に書いておく弱点：

- 中継所には鍵が無く、だれでも呼べます。守っているのは上の回数の上限と Google の1日の枠です（開発記録 11/07 18:12）。
- 回数はサーバー1台のメモリの中だけで数えます。Vercel がサーバーを増やすと、全体で60回を少し超えることがあります（推測で、確かめていません）。
- 枠を使い切られると、その日は自然な声の代わりに iPhone の声になります。記録や相談は影響を受けません。
- 本物のアプリからの通信だけを通す仕組み（Apple の App Attest）は、提出後の宿題です。
- Google の規約では、無料のキーだと送った文がサービスの改善に使われることがあります。藤川さんは 11/03 に有料プランのキーを選びました（開発記録 11/03 11:07）。ただし、中継所に入れたキーがそのキーかは、開発記録には書かれていません。

## 脅威と対策

| 脅威 | 対策 | 残る限界 |
|---|---|---|
| AI が記録に無いことをもっともらしく答える | 根拠の日付が、実際に送った日に含まれなければ「見当たりません」（`Answerer.verify`）。日付の文言はアプリが組み立てる | 送った日の中での取り違えは、形だけでは防げない。採点で確かめている（[採点.md](採点.md)） |
| ヒントに答えが入っている | 正解とみなす言葉を含むヒントを捨てる（`HintSession.matches`）。代わりのヒントも同じ点検にかける | 言い換えで答えを言うヒントは見抜けない。指示文で禁じ、採点でヒントを人の目で読んでいる |
| 鍵がリポジトリに入る | `.githooks/pre-commit`、GitHub Actions の点検（全履歴）、`.gitignore`、Claude Code のフック `guard_secrets.py`（書き込む前に止める） | pre-commit は `git config core.hooksPath .githooks` が要る。Actions が二重の網 |
| 鍵がバックアップで別の端末へ | キーチェーンに「この iPhone だけ」で保存 | — |
| 中継所の悪用 | 上の「声の中継所の制限」 | 上の弱点 |
| 試験用の起動の仕組みが配るアプリに残る | 記録を消す・鍵を渡すなどの起動引数と環境変数は `#if DEBUG` の中だけ（[DowasureApp.swift](../App/DowasureApp.swift)） | — |
| 架空の記録で本物の記録を上書き | 記録がある日には架空の記録を入れない（`loadSamples`） | — |
| 間違えて全部消す | 「記録の保管」のさらに奥に置き、日数つきの確認を出す。先に書き出すよう書き添える | 消した後は戻せない |
| 紛失・故障で記録が消える | 書き出し（テキストファイル）。iPhone のバックアップがオンなら移せる | バックアップも書き出しもしていなければ戻せない |
| 保存の場所が開けない | 落ちずに起動し、記録のファイルは消さない（`DowasureApp.init`） | その間に話したことはアプリを閉じると残らない（画面で伝える） |
| 医療めいた機能や言葉 | 医療・診断の機能は入れていない。AI への指示文に「医療的な判断や助言は書かない」（`Prompts.swift`）。ホームに「このアプリは暮らしの助けです。医療や診断は行いません。」。Claude Code のフック `check_wording.py` が App と中核に医療めいた言葉が入ると知らせる | — |
| 実在の人の記録がリポジトリに入る | デモ用のデータは `SampleData.swift` と `Fixtures/` の架空のものだけ。公開前の点検（`.claude/skills/pre-publish-check/`） | — |

## このリポジトリの安全

このリポジトリは公開します。そのための決まりです。

| 決まり | 仕組み |
|---|---|
| 鍵を入れない | [`.githooks/pre-commit`](../.githooks/pre-commit) が、Anthropic の鍵（`sk-ant-`）・Google の鍵（`AIza`）らしい文字列を含むコミットを止める |
| 鍵と個人の記録のフォルダを入れない | `.gitignore` で `secrets/`・`private-data/` を除外し、pre-commit でも止める |
| 押し忘れても気づく | GitHub Actions の「点検」（[secret-scan.yml](../.github/workflows/secret-scan.yml)）が、プッシュのたびに全履歴を点検する。見つけた文字列そのものはログに出さない |
| Claude が書く前に止める | [`.claude/settings.json`](../.claude/settings.json) のフック。鍵と `secrets/`・`private-data/` への書き込みを止め、公開の切り替えと強制 push は確認を出す |
| 実在の人の記録を入れない | デモ用のデータは架空のものだけ |
| 作者のメールアドレスを出さない | コミットの作者は GitHub の非公開用アドレス（11/03 07:45 に書き換え） |

公開前には、Claude Code のサブエージェント（本体とは別の目）に全履歴を点検させました（2026-11-03 07:45）。結果：API キー・実在の個人情報なし。リポジトリはその後、藤川さんの判断で提出まで非公開にしています（11/03 15:32）。公開へ戻す前に、同じ点検をします。

問題を見つけた時の連絡方法は [SECURITY.md](../SECURITY.md) にあります。
