# プライバシーと安全

ど忘れ相棒が「どこに何を送り、何を保存するか」を、すべて書き出します。最終更新：2026-11-03。

## ひとことで

- 記録は **iPhone の中だけ** に保存します。開発者のサーバーはありません。
- AI に送るのは、**処理に必要な分だけ** です。
- 鍵（API キー）は **iPhone のキーチェーン** に保存し、このリポジトリにもアプリにも入れていません。

## 保存するもの

| 何を | どこに | 補足 |
|---|---|---|
| 話した言葉と、その日の抜き出し結果 | iPhone の SwiftData（アプリ内のデータベース） | iCloud への同期の設定はしていない（`project.yml` に iCloud の権限が無い） |
| 記録の控え（書き出した時だけ） | 書き出した人が選んだ場所（ファイル App、AirDrop、メールなど） | 設定 →「記録の保管（ご家族向け）」→「記録を書き出す」で、テキストファイルにする。アプリが自分から外へ送ることはない。機種変更の時は、iPhone の iCloud バックアップ（または直接転送）で記録も移る。キーは移らないので入れ直す |
| Claude API の鍵、Gemini API の鍵 | iPhone のキーチェーン | 「この iPhone だけ」の設定（`kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`）。バックアップで別の端末に移らない |
| 決まり文句の声（「覚えておきたいことを、話してください。」など） | iPhone のキャッシュ用フォルダ | 個人の記録を含む声は保存しない |
| 設定（声の種類、お知らせの時刻） | iPhone のアプリ設定 | — |

記録は、設定画面の「はじめの準備（ご家族向け）」から、確認のうえすべて消せます。

## 送るもの

| 送り先 | 送るもの | いつ |
|---|---|---|
| **Anthropic**（Claude API） | その日に話した言葉 | 「覚えておくことを話す」の後、人・約束などを抜き出す時 |
| **Anthropic**（Claude API） | 質問と、関係のありそうな日の記録（最大7日分） | 「あれ、何だっけ？」で聞いた時 |
| **声の中継所**（作者の Vercel）→ **Google**（Gemini API の音声合成） | 読み上げる文（答えやヒントを含む） | 自然な声で話す時。中継所は文を保存も記録もせず、そのまま Google に取り次ぐ。設定で「すぐ話す声」にすれば送らない |
| **Apple**（音声認識） | 話した声 | iPhone の中で文字にできない時だけ。できる時は端末内で処理する |

- 送らないもの：すべての記録をまとめて送ることはしません。候補日はアプリが端末内で選びます。
- 利用者は Google の鍵を入れません。鍵は中継所の環境変数にだけ置きます（アプリにもリポジトリにも入れない）。中継所の Gemini の鍵は **有料のキー** にします。Google の規約上、無料のキーでは送った文がサービスの改善に使われることがあるためです（2026-11-03 に公式の料金表で確認。[開発記録](開発記録.md) 11:05 の項）。
- Anthropic の Managed Agents は使っていません。会話がサーバー側に保存される仕組みで、「記録を端末の外に保存しない」という約束と合わないためです。

## 作り話を防ぐ

| 心配 | 対策 |
|---|---|
| AI が、記録に無いことをもっともらしく答える | 根拠の日付が、実際に AI に渡した日に含まれなければ「見当たりません」と答える（`Answerer.verify`） |
| AI が根拠の日付を書き間違える | 「◯月◯日の記録より」の文言は AI ではなくアプリが組み立てる |
| ヒントに答えがそのまま入っている | 答えの言葉が入ったヒントはアプリが捨てる |

限界もあります。言葉は違っても、実質的に答えになっているヒント（例「数字は『三』と『二』を並べたもの」）は、自動の検査では見抜けません（[開発記録](開発記録.md) 14:19 の項）。

## 医療・診断について

医療や診断めいた機能・文言は入れていません。AI への指示文にも「医療的な判断や助言は書かない」と入れています（`Prompts.swift`）。

## このリポジトリの安全

このリポジトリは公開します。そのための決まりです。

| 決まり | 仕組み |
|---|---|
| 鍵を入れない | `.githooks/pre-commit` が、Anthropic の鍵（`sk-ant-`）・Google の鍵（`AIza`）らしい文字列を含むコミットを止める |
| 鍵と個人の記録のフォルダを入れない | `.gitignore` で `secrets/`・`private-data/` を除外し、pre-commit でも止める |
| 押し忘れても気づく | GitHub Actions の「秘密情報の点検」が、プッシュのたびに同じ点検をする（`.github/workflows/secret-scan.yml`） |
| 実在の人の記録を入れない | デモ用のデータは `SampleData.swift` と `Fixtures/` の架空のものだけ |
| 作者のメールアドレスを出さない | コミットの作者は GitHub の非公開用アドレス |

公開前には、Claude Code のサブエージェント（本体とは別の目）に全履歴を点検させました（2026-11-03 07:45）。結果：API キー・実在の個人情報なし。

問題を見つけた時の連絡方法は [SECURITY.md](../SECURITY.md) にあります。
