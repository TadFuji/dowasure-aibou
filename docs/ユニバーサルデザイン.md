# シニアフリー・ユニバーサルデザイン

ど忘れ相棒を使うのは、主に高齢の方です。目が見えにくい、高い音が聞こえにくい、操作に時間がかかる、という前提で、アプリ全体の決まりを作りました。最終更新：2026-11-03。

> 「高齢者は高周波は聞こえないことも考慮してください。ユビキタス、全体的に。」
> — 藤川（2026-11-03 14:30）

この決まりは、Claude Code への説明書（[`CLAUDE.md`](../CLAUDE.md)）にも書いてあります。どのセッションの Claude も、同じ決まりで作ります。

## 見る

| 決まり | 具体的に | 確かめ方 | コード |
|---|---|---|---|
| 文字とボタンは大きく | 主なボタンの高さ120pt、「ホームにもどる」80pt。文字は `title` 以上 | シミュレーターで目視 | `Style`、`BigButton` |
| 最大の文字サイズでも切れない | ボタンの文字は「…」で途切れず折り返す。ホームはスクロールできる | iPhone の文字サイズを最大にして目視（11/03） | `wrapsForLargeText()` |
| 白い文字の背景はコントラスト比4.5以上 | 濃いオレンジ 5.31、濃い緑 5.45、濃い赤 5.91（iPhone 標準のオレンジ・緑は約2.2で不可） | 計算（検算済み・Python） | `Palette` |
| 色だけに頼らない | 注意やエラーは、赤い文字に加えて三角の印と言葉で示す | 画面テスト | `WarningText` |
| 戻り方が分かる | 左上の小さな矢印をやめ、どの画面にも下に大きな「ホームにもどる」 | 画面テスト | `ElderScreen` |

コントラスト比は WCAG 2.x（Web のアクセシビリティの国際的な目安）の計算式で求めました。AA の基準は、普通の大きさの文字で4.5以上です。

## 聞く

| 決まり | 具体的に | コード |
|---|---|---|
| 音は低く | 待ち時間の「ポンポンポン」は 392Hz（ソ）。倍音を含めて1kHz未満。こだまの高い成分は1.5kHzで切る | `Voice.swift` |
| 冷たくない音 | 立ち上がりがやわらかく、長く消えていく木琴のような音に、こだまと広い部屋の響き | `Voice.swift` |
| 声は低め・ゆっくり・はっきり | Gemini には「少し低めでやわらかく、ゆっくり、子音をはっきり」と指示。iPhone の声は高さ0.9倍 | `Voice.swift` |
| 怖くない声 | 機械っぽい変わった声（Eddy など）は候補から外す。既定は Gemini の自然な声 | `Voice.swift` |
| 音だけに頼らない | 話した言葉、ヒント、答えは必ず文字でも表示する | 各画面 |

## 話す・操作する

| 決まり | 具体的に | 理由 |
|---|---|---|
| 考える時間を待つ | 話し始めるまで20秒待つ。話し始めてからは4秒の間で区切る | 「何を話すか考えているうちに、元に戻ってしまいます」（藤川、11/03） |
| 始まりと終わりを振動でも | マイクが聞き始めた時と止まった時に、短い振動 | 耳が聞こえにくい方でも分かるように |
| 聞き間違いに気づける | 話した言葉を「『…』ですね。覚えました。」とそのまま読み返す | 音声認識の間違いを、その場で直せるように |
| 間違いは取り消せる | 「いまのを取り消す」で直前の1件を消す | 操作の失敗を怖がらずに使えるように |
| 答えはすぐ言わない | まずヒント。名前を言えば「そうです！」、「答えを教えて」で答え | 自分で思い出せた方がうれしい（アプリの目的） |
| 準備は家族向けに分ける | 鍵の入力などは「はじめの準備（ご家族向け）」に畳む | ふだん使う人が迷わないように |

## まだ確かめていないこと

- VoiceOver（画面読み上げ）での操作の通し確認。
- 実際の高齢の方（藤川以外）による試用。
- 毎晩のお知らせが実機で届くか（シミュレーターでは通知の許可がもらえないため）。
