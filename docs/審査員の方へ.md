# 審査員の方へ（5分で読める案内）

配点の4項目ごとに、見てほしい所と、その証拠のファイルをまとめました。数字はすべて、コード・git・[開発記録](開発記録.md)で確かめたものです。確かめていないことは書いていません。最終更新：2026-11-07 夜。

## 一言で

**忘れそうなことをパッと話すと覚えてくれて、「何だっけな」の時は、答えではなくヒントで、自分で思い出す手伝いをする iPhone アプリです。**

制作者の藤川（65歳）はプログラマーではありません。コードは1行も書いていません。企画・実機での試用・判断を藤川が、設計・実装・テスト・記録を Claude Code が担当しました。

## 配点ごとに「ここを見てください」

### インパクト（30%）：誰が、どれだけ困っているか

- **使う人と場面**：「さっき聞いた名前」「来週の約束」「買う物」がふっと出てこない高齢の方。小さな文字を打つメモは続かない。だから「話すだけ」で残す。→ [README「誰の、何を助けるのか」](../README.md)
- **作り手が当事者に近い**：65歳の藤川が自分の iPhone 15 Pro Max で使い、感じたことをそのまま伝えて作りを変えました。藤川の言葉は [開発記録の言葉の表](開発記録.md#藤川さんの言葉指示困ったこと気持ち) に81行あり、それぞれ「受けて変えたこと」と並べています。
- **続けて使う仕組み**：毎晩のお知らせ（[`EveningReminder.swift`](../App/EveningReminder.swift)）、Siri の一言で開く（[`SiriShortcuts.swift`](../App/SiriShortcuts.swift)、言い方7つ）、ヒントだけで言い当てた回を数えて「この1週間で、ご自分で◯回思い出せました。」と出す（[`RecallLog.swift`](../DowasureCore/Sources/DowasureCore/RecallLog.swift)）。0回の時は何も出しません。採点されている感じを避けるためです（[11/07 16:18 の決めごと](開発記録.md#1618-3つの機能の細かい決めごとなぜそうしたか)）。
- **2年使っても重くならない見積もり**：多めに1日2,000文字と見て2年で約4.4MB。質問1回に送るのは最大7日分（検算済み、[11/07 16:14](開発記録.md#1614-作りたいものから外れていないか点検したコードは変えていない)）。

### デモ（25%）：何をどう解決するか

デモ動画は 11/08 に撮る予定です（[開発記録 11/07 11:50](開発記録.md#1150-レビューで見つかった改善点を1つずつ直した) の藤川の言葉）。動画の前でも、次の2つで流れを確かめられます。

1. [README「使い方の流れ」](../README.md) の図：話す → 覚える → 「何だっけ」→ ヒント → 本人が言い当てる → 「そうです！」と日付つきの答え。
2. 画面の通しテスト [`testTalkThenAskWithKey`](../UITests/FlowUITests.swift#L82)：本物の Claude を使い、「青山さんに本を返す」と話す → 「今日、本を返す相手の名前」と聞く → 最初の返事が「ヒントです」で始まり、**「青山」を含まない** → 「答えを教えて」で「◯月◯日の記録より：…青山…」になる、までを機械で確かめています。

見てほしい場面：最初の返事が答えではなくヒントであること。ヒントだけで言い当てた時の、低めのチャイムと振動と「ご自分で思い出せましたね」。音量が0でも、文字と振動だけで最後まで使えること（[11/07 19:20](開発記録.md#1920-音量が0でも使えるようにした声を待たせない)）。

アプリの中の AI（Claude Haiku 5.5）は、**言葉の仕事だけ** を任せ、確かめる仕事はコードが持ちます。

- 根拠の日付の検証：[`Answerer.verify`](../DowasureCore/Sources/DowasureCore/Services.swift#L73)。AI が返した日付のうち、**実際に AI へ渡した日だけ** を残し、「10月8日の記録より」の文はコードが組み立てる。残らなければ「見当たりません」。
- ヒント漏れの除去：[同じ関数の84〜93行](../DowasureCore/Sources/DowasureCore/Services.swift#L84-L93) と [`HintSession.matches`](../DowasureCore/Sources/DowasureCore/HintSession.swift#L98)。漢字・かな・全角半角・「さん」を揃えて比べ、答えを含むヒントを捨てる。
- ヒントの指示文：[`Prompts.answerSystem`](../DowasureCore/Sources/DowasureCore/Prompts.swift#L55)。3段の決まりと、5種類（人・予定・場所・数字・物の置き場所）の手本。
- 送る量を絞る：[`Retriever`](../DowasureCore/Sources/DowasureCore/Retriever.swift#L44) が端末内で候補日を最大7日に絞る。
- これらを確かめる単体テスト：[`evidenceOutsideCandidatesIsRejected`](../DowasureCore/Tests/DowasureCoreTests/CoreTests.swift#L272)、[`hintThatLeaksAnswerIsDropped`](../DowasureCore/Tests/DowasureCoreTests/CoreTests.swift#L452)、[`dateHintIsNotUsedWhenTheDateIsTheAnswer`](../DowasureCore/Tests/DowasureCoreTests/CoreTests.swift#L473)。

### 深さと実行力（20%）：試行錯誤の跡と、安心して使える作り

- **時系列の全記録**：[開発記録.md](開発記録.md)。藤川の言葉83行、うまくいかなかった案40行以上（どちらも表の行を数えた）。藤川の言葉と直した点を13行で並べた一覧は [README の「細かく直した跡」](../README.md#細かく直した跡ひと目で)。
- **ヒントの決まりを、測って3回直した**：本物の Claude で4回採点し、出たヒントを全部読んだ。自動の判定（答えの言葉が入っているか）は4回とも漏れ0件だったが、読むと「『や』で始まる、走り回るスポーツ」（野球）、「雪のような色」（白）、1けたの数で最初の数字＝答え、という漏れが見つかった。AI が考える量を減らすと速くなる（平均4.4秒 → 2.4秒）が漏れが増えたので、速さより「答えを言わない」を選んだ。→ [11/07 17:45〜18:00](開発記録.md#17451800-mac-で確かめヒントの決まりを3回直した)
- **声の試行錯誤**：iPhone の声 →「ロボットっぽくて怖い」→ 自動で選んだ声が逆に怖い声 → Gemini の声 → 1日の上限で途中で声が変わる → 予備のモデルと同梱の録音。→ [うまくいかなかった案の表](開発記録.md#うまくいかなかったことあきらめた案)
- **安心の作り**：記録は端末の中だけ（[プライバシーと安全.md](プライバシーと安全.md)）。鍵はキーチェーン。保存の場所が開けない時は落ちずに「記録は消していません」と伝える（[`DowasureApp.swift`](../App/DowasureApp.swift#L76)）。白い文字の背景色はコントラスト比4.5以上（[`Palette`](../App/DowasureApp.swift#L88)）。

## 正直な限界

- **採点データは小さく、Claude が作ったもの。** 架空の記録25日・質問30問です。このデータを見ながら検索を直したので、実際より良い点が出ている恐れがあります（[採点.md](採点.md)）。藤川の実際の記録での確かめ直しは、まだです。
- **ヒント漏れの自動の判定は、言葉の一致だけ。** 言い換えの漏れは、人の目で読んで見つけています。
- **実機で確かめていないものがある。** 着信で止まるか、Siri の言い方、音量0での動き、下半分のボタンに親指が届くか（[これからやること](開発記録.md#これからやること)）。
- **使った高齢の方は、藤川1人。** ほかの方の感想はまだありません。
- **声の中継所は鍵なしで呼べる。** 回数の上限と Google 側の1日の枠で、費用が増え続けないようにしています（[11/07 18:12](開発記録.md#1812-声の中継所はだれでも呼べるという指摘を確かめた)）。
- **医療や診断は行いません。** 暮らしの中で、自分で思い出す手伝いをするアプリです。
