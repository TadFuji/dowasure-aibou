# 審査員の方へ（5分で読める案内）

> **3行でいうと**
> 1. **答えを教えず、思い出す手伝いをします。** 忘れそうなことを話せば覚え、「何だっけ」の時はヒントを3段で出します。答えの言葉がそのまま入ったヒントはコードが捨て、言い換えの漏れは別の Claude（ヒントの係）が読んで点検しました。医療や診断はしません。
> 2. **高齢の方のために、細かいところまで作り込みました。** 65歳の藤川が実機で試し、その言葉で直す、を繰り返しました。直したことは [11行の表](../README.md#高齢者に使いやすくするために直したこと)に、藤川の言葉80件以上とうまくいかなかった案40件以上は [開発記録](開発記録.md) に残しています。
> 3. **何人もの Claude で、いろいろな方向から作り、点検しました。** 4人の係（Claude Code のサブエージェント。高齢の利用者役・ヒントの審査員・iOS の技術者・大会の審査員）に点検させて26件を直しました（[係の点検](係の点検.md)）。鍵の書き込みや医療めいた言葉は、フックが止めたり知らせたりします（[Claude活用](Claude活用.md)）。

配点の4項目ごとに、見てほしい所と、その証拠のファイルをまとめました。数字はすべて、コード・git・[開発記録](開発記録.md)で確かめたものです。確かめていないことは書いていません。最終更新：2026-11-08。

## 一言で

**忘れそうなことをパッと話すと覚えてくれて、「何だっけな」の時は、答えではなくヒントで、自分で思い出す手伝いをする iPhone アプリです。**

制作者の藤川（65歳）はプログラマーではありません。コードは1行も書いていません。企画・実機での試用・判断を藤川が、設計・実装・テスト・記録を Claude Code が担当しました。

## 配点ごとに「ここを見てください」

### インパクト（30%）：誰が、どれだけ困っているか

- **使う人と場面**：「さっき聞いた名前」「来週の約束」「買う物」がふっと出てこない高齢の方。小さな文字を打つメモは続かない。だから「話すだけ」で残す。→ [README「誰の、何を助けるのか」](../README.md)
- **作り手が当事者に近い**：65歳の藤川が自分の iPhone 15 Pro Max で使い、感じたことをそのまま伝えて作りを変えました。藤川の言葉は [開発記録の言葉の表](開発記録.md#藤川さんの言葉指示困ったこと気持ち) に80行以上あり、それぞれ「受けて変えたこと」と並べています。
- **続けて使う仕組み**：毎晩のお知らせ（[`EveningReminder.swift`](../App/EveningReminder.swift)）、Siri の一言で開く（[`SiriShortcuts.swift`](../App/SiriShortcuts.swift)、言い方7つ）、ヒントだけで言い当てた回を数えて「この1週間で、ご自分で◯回思い出せました。」と出す（[`RecallLog.swift`](../DowasureCore/Sources/DowasureCore/RecallLog.swift)）。0回の時は何も出しません。採点されている感じを避けるためです（[11/07 16:18 の決めごと](開発記録.md#1618-3つの機能の細かい決めごとなぜそうしたか)）。
- **2年使っても重くならない見積もり**：多めに1日2,000文字と見て2年で約4.4MB。質問1回に送るのは最大7日分（検算済み、[11/07 16:14](開発記録.md#1614-作りたいものから外れていないか点検したコードは変えていない)）。

### デモ（25%）：何をどう解決するか

デモ動画は 11/08 に撮る予定です（[開発記録 11/07 11:50](開発記録.md#1150-レビューで見つかった改善点を1つずつ直した) の藤川の言葉）。動画の前でも、次の2つで流れを確かめられます。

1. [README「使い方の流れ」](../README.md) の図：話す → 覚える → 「何だっけ」→ ヒント → 本人が言い当てる → 「そうです！」と日付つきの答え。
2. 画面の通しテスト [`testTalkThenAskWithKey`](../UITests/FlowUITests.swift)：本物の Claude を使い、「青山さんに本を返す」と話す → 「今日、本を返す相手の名前」と聞く → 最初の返事が「ヒントです」で始まり、**「青山」を含まない** → 「答えを教えて」で「◯月◯日の記録より：…青山…」になる、までを機械で確かめています。

見てほしい場面：最初の返事が答えではなくヒントであること。ヒントだけで言い当てた時の、低めのチャイムと振動と「ご自分で思い出せましたね」。音量が0でも、文字と振動だけで最後まで使えること（[11/07 19:20](開発記録.md#1920-音量が0でも使えるようにした声を待たせない)）。

アプリの中の AI（Claude Haiku 5.5）は、**言葉の仕事だけ** を任せ、確かめる仕事はコードが持ちます。

- 根拠の日付の検証：[`Answerer.verify`](../DowasureCore/Sources/DowasureCore/Services.swift)。AI が返した日付のうち、**実際に AI へ渡した日だけ** を残し、「10月8日の記録より」の文はコードが組み立てる。残らなければ「見当たりません」。
- ヒント漏れの除去：同じ関数の中の「答えを含むヒントを捨てる」処理と [`HintSession.matches`](../DowasureCore/Sources/DowasureCore/HintSession.swift)。漢字・かな・全角半角・「さん」を揃えて比べ、答えを含むヒントを捨てる。
- ヒントの指示文：[`Prompts.answerSystem`](../DowasureCore/Sources/DowasureCore/Prompts.swift)。3段の決まりと、5種類（人・予定・場所・数字・物の置き場所）の手本。
- 送る量を絞る：[`Retriever`](../DowasureCore/Sources/DowasureCore/Retriever.swift) が端末内で候補日を最大7日に絞る。
- これらを確かめる単体テスト：[`CoreTests.swift`](../DowasureCore/Tests/DowasureCoreTests/CoreTests.swift) の `evidenceOutsideCandidatesIsRejected`、`hintThatLeaksAnswerIsDropped`、`dateHintIsNotUsedWhenTheDateIsTheAnswer`（コードは提出日まで直していたので、行番号ではなく関数の名前で示します）。

### 深さと実行力（20%）：試行錯誤の跡と、安心して使える作り

- **時系列の全記録**：[開発記録.md](開発記録.md)。藤川の言葉80行以上、うまくいかなかった案40行以上（どちらも表の行を数えた。11/07 21:15 に数えて87行と45行）。高齢の方に使いやすくするための試行錯誤を、藤川の言葉・変えたこと・効く理由で並べた一覧は [README の「高齢者に使いやすくするために直したこと」](../README.md#高齢者に使いやすくするために直したこと)。
- **ヒントの決まりを、測っては直した**（採点で3回、係の点検で3回）：本物の Claude で採点し、出たヒントを全部読んだ。自動の判定（答えの言葉が入っているか）は毎回漏れ0件だったが、読むと「『や』で始まる、走り回るスポーツ」（野球）、「雪のような色」（白）、1けたの数で最初の数字＝答え、という漏れが見つかった。AI が考える量を減らすと速くなる（平均4.4秒 → 2.4秒）が漏れが増えたので、速さより「答えを言わない」を選んだ。→ [11/07 17:45〜18:00](開発記録.md#17451800-mac-で確かめヒントの決まりを3回直した)
- **声の試行錯誤**：iPhone の声 →「ロボットっぽくて怖い」→ 自動で選んだ声が逆に怖い声 → Gemini の声 → 1日の上限で途中で声が変わる → 予備のモデルと同梱の録音。→ [うまくいかなかった案の表](開発記録.md#うまくいかなかったことあきらめた案)
- **安心の作り**：記録は端末の中だけ（[プライバシーと安全.md](プライバシーと安全.md)）。鍵はキーチェーン。保存の場所が開けない時は落ちずに「記録は消していません」と伝える（[`DowasureApp.swift`](../App/DowasureApp.swift) の `.alert`）。白い文字の背景色はコントラスト比4.5以上（同じファイルの `Palette`）。
- **テスト**：中核の単体テスト60件（`@Test` を数えた）と画面の通しテスト6本（`func test` を数えた。README の画面写真を撮るだけのテスト1本は別で、ふだんは飛ばす）。成功したのは藤川の Mac での実行で、最後の記録は今のコード（5c5110c）での「単体60件・画面6本すべて成功」（[係の点検](係の点検.md)）。この文書を書いた作業場所には Swift が無く、ここでは実行していません。
- **GitHub の自動点検**：[`.github/workflows/secret-scan.yml`](../.github/workflows/secret-scan.yml) が、全履歴の鍵らしい文字列と文書のリンク切れを毎回点検。11/07 23:00 までに168回動いた（GitHub の API で確認）。11/07 夜に130回の時点で失敗0回を確かめ、その後の main の最新（PR #14 のマージ）も成功。

## 正直な限界

- **採点データは小さく、Claude が作ったもの。** 架空の記録25日・質問30問です。このデータを見ながら検索を直したので、実際より良い点が出ている恐れがあります（[採点.md](採点.md)）。藤川の実際の記録での確かめ直しは、まだです。
- **ヒント漏れの自動の判定は、言葉の一致だけ。** 言い換えの漏れは、人の目とヒントの係（[係の点検.md](係の点検.md)）が読んで見つけています。
- **実機で確かめていないものがある。** 着信で止まるか、Siri の言い方、毎晩のお知らせ（[これからやること](開発記録.md#これからやること)）。音量0での動きは、藤川が実機で音量を0にして試しながら直しました（11/07 19:40〜19:53）が、全画面の通しはまだです。
- **使った高齢の方は、藤川1人。** ほかの方の感想はまだありません。
- **声の中継所は鍵なしで呼べる。** 回数の上限と Google 側の1日の枠で、費用が増え続けないようにしています（[11/07 18:12](開発記録.md#1812-声の中継所はだれでも呼べるという指摘を確かめた)）。
- **医療や診断は行いません。** 暮らしの中で、自分で思い出す手伝いをするアプリです。
